# Независимая модель движения: исходная спецификация

Дата: 2026-10-13. Этот документ фиксирует исходный этап до реализации ядра.
Актуальное расширение репликой клиентских блоков описано в [client-world.md](client-world.md).
Цель — собственный проверяемый симулятор движения для Vesuvio.
Исходники GrimAC не используются. Это не порт GrimAC и не заявление об идентичности
его алгоритмам. В предыдущей работе изучался байткод Vacan; поэтому строгая
организационная изоляция clean-room в рамках этой сессии не обеспечена.
Материалы того анализа не являются спецификацией данного модуля.

## Контракт

1. Ядро — чистая Java без Bukkit, PacketEvents, доступа к миру или наказаниям.
   Вход: позиция, сохраняемая скорость, grounded, размеры тела, параметры физики,
   цифровой ввод, yaw и неизменяемый ограниченный набор collision AABB.
2. За шаг ввод нормализуется, ослабляется коэффициентом 0.98 и поворачивается по yaw.
   На земле ускорение зависит от resolved movement attribute и скользкости;
   в воздухе используется отдельное ускорение. Спринт не применяется к атрибуту дважды.
   Прыжок задаёт вертикальную скорость, спринт-прыжок добавляет направленный импульс.
3. Перемещение ограничивается столкновениями: сначала вертикаль, затем горизонтальные
   оси, начиная с большей компоненты. Ступенька рассматривается отдельным маршрутом
   «подъём — горизонталь — спуск»; выбирается маршрут с большим горизонтальным ходом.
   Заблокированные компоненты скорости обнуляются. После хода применяются трение,
   гравитация и сопротивление воздуха. Это начальный профиль, требующий сверки с
   трассами клиента 26.2, а не доказанная побитовая эмуляция этой версии.
4. Область вне снимка, неполные чанки, пересечение тела с исходной геометрией,
   неподдерживаемая механика и недостоверное время дают UNKNOWN, а не нарушение.
5. Предсказатель перебирает 9 вариантов WASD, спринт, прыжок и замедление ввода.
   Сохраняет несколько правдоподобных состояний, сравнивает предсказанную и принятую
   позицию и публикует расстояние до ближайшего кандидата. Расхождение вызывает
   повторный прогрев; непроверенная скорость клиента не становится допустимой навсегда.
6. Поворот и снимок захватываются для конкретного пакета. Телепорт, смена режима,
   импульс сервера, неизвестная геометрия, смена размеров и пауза сбрасывают историю.
   Пакет без позиции не считается нулевым перемещением: следующий замер прогревается.
7. Интеграция только диагностическая, включается администратором для выбранного игрока.
   Никаких VL, risk, отмен событий или команд наказания от этого модуля.
   Диагностика не подменяет существующие Speed/Fly.

## Источник параметров и геометрии

Начальные числовые параметры общеизвестной модели ходьбы: default movement 0.1,
gravity 0.08, jump 0.42, horizontal air drag 0.91, vertical drag 0.98,
обычная скользкость 0.6. Они записаны здесь явно, до реализации. Основные атрибуты
и реальные формы блоков поставляет установленный Paper API 26.2; код античитов
для их получения не требуется. Тесты проверяют аналитические числа, геометрию и
инварианты, а не используют вывод симулятора как единственный эталон.

Для адаптера проверены объявления `Attribute.GRAVITY`, `STEP_HEIGHT` и API
`Block.getCollisionShape()` в Paper API 26.2.build.100-stable. Чтобы установить
систему координат AABB, просмотрены только методы API-обвязки Paper
`CraftBlock.getCollisionShape` и `CraftVoxelShape.getBoundingBoxes` (ветка main,
2026-10-13): формы локальны блоку. Код этих методов не переносился. Физика
Minecraft/GrimAC из исходников или декомпиляции в этой работе не исследовалась.

## Границы первой интеграции (историческое состояние)

Снимок Paper показывает мир сервера, а не подтверждённый мир клиента. Нет истории
отправки/подтверждений чанков, блоков, атрибутов и entity collisions. Жидкости, элитры,
транспорт, лазание, специальные блоки, эффекты прыжка/левитации/плавного падения,
нестандартные позы и серверные импульсы исключаются. Сравнение только при обычной
частоте поступления пакетов; receive time не доказывает количество клиентских тиков.
Из-за этих ограничений автоматическое применение наказаний намеренно отсутствует.

Следующий этап заменил серверную геометрию на реплику исходящих пакетов чанков и
блоков с маркерами Ping/Pong. Атрибуты, поза и ряд исключений пока остаются серверными;
точность клиентского тика не гарантируется. Подробнее в [client-world.md](client-world.md).

## Критерии проверки

- Независимые числовые примеры ходьбы, спринта, диагонали, прыжка и падения.
- Пол, потолок, стена, скольжение по стене, полуплита, высокая ступень и низкий потолок.
- Сохранение энергии ограничено трением; диагональ не увеличивает силу ввода.
- Возможная траектория проходит; ускорение, зависание и полёт сквозь стену расходятся.
- Телепорт/импульс/пауза/новый мир не сравниваются с историей до перехода.
- Отключённая диагностика не сканирует collision shapes и не влияет на VL.
- Живые трассы Paper 26.2 + BetterRTP необходимы отдельно; unit-тесты их не заменяют.
