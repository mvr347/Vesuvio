# Разбор срабатываний из LoveWebAdmin

Для работы обновите оба плагина. Новая capability `violation-reviews` добавляет постоянные ID и сохранённые решения к историческим срабатываниям. Старые методы API и их временные единицы не меняются.

- «Чит» / «Не чит» относится к одному событию. Это не постоянное исключение для игрока, не автоматический бан и не сброс текущего VL.
- Вердикт, сотрудник, обоснование, время и версия сохраняются в таблицах `vesuvio_violation_reviews` и `vesuvio_violation_review_history`. Старое событие остаётся в журнале. Неверная версия не перезаписывает новое решение другого сотрудника.
- Решение и запись аудита фиксируются одной транзакцией. Ошибка аудита откатывает изменение. Данные читаются с ограничением до 200 событий и индексом по времени/ID.
- ML-образцы разбираются отдельно через существующие `getPendingReviews` / `submitReview`. Их настоящие векторы передаются в соответствующий классификатор кликов или прицеливания и датасет с источником STAFF. Обычная запись Speed, Timer или Baritone не подменяет отсутствующий обучающий вектор.
- Онлайн-классификатор обновляется при разборе образца. Обновление ONNX остаётся под управлением существующего автообучения с его требованиями к количеству образцов.

## Исправление ложного Baritone

Прежняя эвристика считала длительное совпадение взгляда и направления движения признаком бота. Обычное удержание W без движения мыши воспроизводит этот признак в ванильной игре. Регрессионный тест воспроизвёл флаг на такте 49 (50-й проверке).

Такое выравнивание больше не повышает VL. Совместимая точка входа BaritoneCheck сохранена; настройка выключена по умолчанию. Эта замена не является новым детектором Baritone: независимые признаки ещё нужно разработать и проверить. Старые события не удаляются. Исправление не заявляет устранение других ложных срабатываний Speed, InvMove или Timer без воспроизведения их условий.

Проверено: SQLite, атомарность аудита, конфликт версий, конкурентный разбор и сохранность после повторного открытия. Живой Paper/Purpur и PostgreSQL в этой среде не проверялись.
